Devara Playground

A programming language written in romanized Telugu. The verb comes last: x ni chupi — “show x”. Everything runs in your browser; nothing is uploaded.

Cheat sheet

x lo 5 pettu assign
x + 1 ni chupi print
x ni chaduvu read input
c ayite { } lekunte { } if / else
c unnanta varaku { } while
prati i 1 nundi 10 varaku { } range loop
int f charya (int a) { a * 2 ivvu } function
aapu / saagu break / continue
